# USER_GUIDE.md — คู่มือการใช้งานระบบเมนูชุมชน

**ชื่อแอปพลิเคชัน:** เมนูชุมชน (Community Menu Planner)  
**เวอร์ชัน:** 1.0.0  

---

## 1. วิธีเริ่มใช้งานโปรแกรม

1. เปิด Terminal หรือ Command Prompt
2. เข้าสู่โฟลเดอร์ของโปรแกรม
3. รันคำสั่ง:
   ```bash
   python main.py
   ```
4. โปรแกรมจะสร้างฐานข้อมูล `community_menu.db` พร้อมข้อมูลจำลองสำหรับทดลองใช้งานทันทีโดยไม่ต้องตั้งค่าฐานข้อมูลเพิ่มเติม

---

## 2. หน้าจอการทำงานหลักทั้ง 7 ส่วน

### 2.1 หน้าหลัก (Dashboard)
- แสดงการ์ดสรุปยอดวัตถุดิบใกล้หมด, ล็อตใกล้หมดอายุ, คำสั่งซื้อรอรับ และยอดซื้อจากชุมชน 30 วันล่าสุด
- ตารางเตือนวัตถุดิบที่ต่ำกว่าเกณฑ์ขั้นต่ำ (สีแดง)
- ตารางเตือนล็อตที่ใกล้ถึงหรือเลยวันควรใช้ก่อน (สีส้ม/แดง)

### 2.2 คลังวัตถุดิบ (Inventory)
- ค้นหา เพิ่ม และแก้ไขข้อมูลวัตถุดิบ
- ปุ่ม **รับเข้า** (บันทึกรับของเข้าคลังเป็นล็อตใหม่พร้อมวันควรใช้ก่อน)
- ปุ่ม **เบิกใช้** (ระบบจะคำนวณเสนอล็อตที่หมดอายุก่อนให้อัตโนมัติแบบ FIFO)
- ปุ่ม **บันทึกของเสีย** และ **ปรับยอด** (ต้องระบุเหตุผลเพื่อบันทึกประวัติทุกครั้ง)

### 2.3 สูตรอาหาร (Recipes)
- กำหนดสูตรอาหารโดยระบุปริมาณวัตถุดิบต่อ 1 จาน
- ปริมาณจะถูกคูณตามจำนวนจานอัตโนมัติเมื่อวางแผนเมนู

### 2.4 ข้อมูลชุมชน (Community)
- บันทึกรายชื่อเกษตรกรและข้อมูลติดต่อ
- บันทึกผลผลิตที่พร้อมขาย ราคาต่อหน่วย ปริมาณพร้อมขาย และวันที่พร้อมส่ง

### 2.5 แผนเมนูและ AI (Planner)
1. ระบุ **งบซื้อเพิ่ม** และ **จำนวนจานต่อเมนู**
2. เลือกเมนูที่ไม่ต้องการ (ถ้ามี)
3. กดปุ่ม **ให้ AI แนะนำเมนู** หรือเลือกเมนูเองในส่วนที่ 2
4. โปรแกรมจะคำนวณวัตถุดิบที่ต้องใช้ เปรียบเทียบกับของในคลัง และหายอดซื้อเพิ่มจากเกษตรกรที่ถูกที่สุดให้อัตโนมัติ
5. กดปุ่ม **ยืนยันแผน + สร้างคำสั่งซื้อ**
6. เมื่อทำอาหาร ให้กดปุ่ม **ยืนยันเบิกวัตถุดิบตามแผน**

### 2.6 การจัดซื้อ (Purchasing)
- แสดงรายการคำสั่งซื้อที่รอรับสินค้า
- กดปุ่ม **รับสินค้าเข้าคลัง** เพื่อสร้างล็อตวัตถุดิบใหม่เข้าสู่คลังทันที

### 2.7 รายงาน (Reports)
- เลือกระบุช่วงวันที่ที่ต้องการดูรายงาน
- สรุปยอดซื้อแยกตามเกษตรกร และประวัติการเบิกใช้/ของเสีย
